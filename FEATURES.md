# Features

## Shipped (v0.1)

| Area | What it does |
|---|---|
| Dashboard | Stats, featured procedures for the active vehicle, system browser, shortcuts |
| 3D viewer | Orbit/zoom, explode slider, click-to-inspect 24 components, running-gear animation, turntable, reset/assemble, WebXR Enter-VR button |
| Procedures | 5 seeded jobs incl. EC1/EC3 head gasket (34+12 steps) and timing cover (13+8); safety + tools + tips; per-step torque and 3D links; progress persisted |
| Diagnostics | 12 DTCs with severity, causes, fixes and links to related procedures |
| Vehicles | 4 Jeep profiles (EC1/EC3, eTorque/ESS flags); global active-vehicle filter |
| Parts | 20 parts with numbers, pricing, stock badges, bin locations |
| Torque | 16 specs with tightening sequences, N·m + ft-lb |
| Search | Global search across procedures, parts, DTCs, torque, wiring |
| Wiring library | 74 factory diagrams in 9 categories, embedded PDF viewer, 9 searchable connector pinouts with wire-color dots |
| OBD live | Web Bluetooth ELM327: live PIDs, DTC read/clear, VIN decode, demo simulator, JScan export importer |
